# Obliq Voice Shoe Store

[Live website](https://obliq-voice-shoe-store.vercel.app/)

A standalone HTML website by Digital Hammerr. All website code is in `index.html`.

## Deployment

This repository connects to the existing Vercel project `obliq-voice-shoe-store`. Pushing to `main` automatically updates the live website. Vercel serves the static files directly, with no build step or dependency installation.

## Making changes

1. Edit `index.html` and check the website in your browser.
2. Commit the changes and push to `main`.
3. Vercel deploys the update to the live URL above.

## Local configuration

`.vercel/` and `.env*` are local Vercel configuration and credentials. They are ignored by Git and excluded from deployment.

Camera and voice features, when present, require a supported browser and browser permission. Store checkout flows are demonstrations.
